### 문제 설명 : 사용자 정보를 조회하는 API 서버 동작 중


### 목표 : Path Traversal(경로 순회) 취약점을 이용해 /api/flag에 있는 플래그 얻기


1. 주어진 웹 서버 접속해서 userid 입력 폼으로 이동한다.
![[화면 캡처 2026-03-30 012039.png]]

> guest를 입력했을 때는 입력란에 0이 잠깐 표시됨
> admin을 입력했을 때는 1이 잠깐 표시됨
> 그러나 둘 다 플래그를 반환하지는 않는다. 


2. 주어진 app.py 파일을 확인한다.
![[화면 캡처 2026-03-30 012019.png]]
- 코드 중 이 부분에서 /api/user/{userid}에 userid를 그대로 넣을 수 있다는 취약점 발견
- userid가 ../flag 같은 경우 기존의 디렉토리를 우회할 수 있다.
- #### 그러나 위 문자열을 그대로 넣으면 숫자로 변환되기 때문에 폼에 입력할 순 없다.


3. 개발자 도구의 콘솔창에서 fetch로 서버에 직접 POST 메서드를 보낸다.
![[화면 캡처 2026-03-30 011801.png]]
- fetch 명령어는 js가 문자열을 검열하는 과정 없이 바로 서버로 전송된다.


4. 콘솔창으로 서버의 응답이 들어온다.
