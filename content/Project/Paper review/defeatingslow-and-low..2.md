1. 플로우가 시작되면 독립적인 2개의 해시 함수로 격자의 시작 좌표(x,y) 설정
2. temporal pattern을 각도와 반지름으로 입력받아 원형 공식 사용해 좌표 변환
	- 반지름 : 평균 패킷 간 도착 지연 시간(AvgIPD)
	- 각도 : 패킷 도착 시간 매핑
	- 시간 역동성이 기하학적 모양으로 변환
3. 리소스를 많이 쓰는 패킷 정보는 바로 스케치 인코딩, 전반적인 메타데이터는 별도의 eBPF 해시 테이블에 저장해 부하 줄임
4. 패킷의 위치가 결정되면 픽셀 값에 메타데이터 쪼개 저장

1. 노이즈 제거 학습
	항상 플로우 정보를 제공하지 않고, 확률적으로만 조건을 알려준다. label이 주어졌을 때와 주어지지 않았을 때의 경우를 모두 학습
	- p : 플로우 단계
	- l : 플로우 유형 및 temporal embedding
	Paired Inputs 기반 손실 계산 : 무작위 타임 스탬프에서 이미지에 가우시안 노이즈를 섞고, 원본 예측 정도를 평균제곱오차(MSE) 손실 함수로 계산
2. 예측 학습
	현재 플로우 상태와 미래(s 시간 이후) 상태를 쌍으로 사용
	- X_past : 새로운 조건, 과거 관측 데이터
	노이즈를 섞은 이미지에서 시작하여 데이터 생성 속도 빠름
